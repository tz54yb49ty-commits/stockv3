## 9. JSON 证据文件

`docs/*.json` 多数是 Markdown 报告的机器可读证据、schema snapshot、backup、preflight 输入输出或 execute 结果。

读取建议：

```text
先读同名前缀的 .md 报告。
需要核对精确行数、P0/P1/P2、schema gap、备份内容时再读 .json。
```

常见类型：

- `*_dry_run.json`：dry-run 机器结果。
- `*_preflight.json`：execute 前检查结果。
- `*_schema_gap*.json`：schema 缺口检查结果。
- `*_migration*_report.json`：migration 执行或评审结果。
- `*_backup_before*.json` / `*_backup_after*.json`：执行前后快照备份。
- `*_execute_report.json`：execute 结果。

JSON 按层前缀归类：

- `N2_*`: 条件层证据。
- `N3_*`: 实时行情层证据。
- `N4_*`: 触发层证据。
- `N5_*`: 动作层证据。
