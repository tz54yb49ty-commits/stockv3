- Worker start, delivery, notification, voice, mobile, sim, position, or real trade.

## Semantic Mapping

Classification baseline keeps the previous-period classification trace:

```text
classification_previous_open = legacy previous_open
classification_previous_close = legacy previous_close
classification_previous_entity_high = legacy previous_entity_high
classification_previous_entity_low = legacy previous_entity_low
classification_previous_amount_baseline = legacy previous_amount_baseline
classification_period_key_previous = legacy period_key_previous
```

N4 trigger baseline must use the source-trade-date current seed:

```text
trigger_previous_open = current_open_seed
trigger_previous_close = current_close_seed
trigger_previous_entity_high = max(current_open_seed, current_close_seed)
trigger_previous_entity_low = min(current_open_seed, current_close_seed)
trigger_previous_amount_baseline = current_amount_seed or current_avg_amount_seed
baseline_source_trade_date = source_trade_date
```

Legacy `previous_*` fields may remain only as classification trace. N4 context must not localize them as trigger baseline.
