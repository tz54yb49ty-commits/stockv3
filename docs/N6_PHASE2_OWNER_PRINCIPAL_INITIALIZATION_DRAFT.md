# N6 Phase 2 Owner Principal Initialization Draft

Status: DRAFT_PASS

Layer role: N6_user

Date: 2026-06-05

This gate drafts Track B Phase 2 owner / principal initialization only. It does
not execute seed SQL, write database rows, consume or update outbox rows, start
workers, modify N6_UI_v1, modify existing APIs, modify existing projection or
shadow pipeline code, deliver notifications, push to voice/mobile, run sim,
create positions, or place real trades.

## 1. Scope

Phase 2 initializes the minimum ownership roots needed before future Track B
multi-user and AI work can be reviewed:

```text
admin principal
system principal
optional reserved AI principal: deferred by default
admin_shadow account: draft-only, allowed only if final gate approves
```

Phase 2 does not create:

```text
human trading user
active AI actor
virtual order
virtual position
AI decision runner
AI evaluation
virtual intent
strategy execution
real account
real funds
real holding
```

identity columns, the executable seed must use stable `seed_key` values before

`account_id`; rollback must not depend on preallocated identity values.

### 4.3 Reserved AI Principal

Default Phase 2 decision:

```text
deferred
```

Reason:

```text
036 allows n6_principal.principal_status in active/disabled/deleted/system_reserved
and n6_ai_user.status in active/disabled/deleted/sandbox_only.
The requested exact reserved/inactive wording is not a 036 enum value.
```

Allowed future compatibility option, if a later final gate explicitly includes
a reserved AI seed:

```text
n6_principal.principal_type = ai_user
n6_principal.principal_status = system_reserved
n6_ai_user.status = sandbox_only
```

Hard boundaries for any future reserved AI seed:

```text
no active AI actor
no AI decision runner
no AI evaluation
no virtual intent
no virtual order
no virtual position
no real trade
```
