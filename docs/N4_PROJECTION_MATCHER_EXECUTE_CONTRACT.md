## Execute Gate

```text
--execute
--user-confirmed
```

Preflight refresh uses:

```text

```

## Rollback

Rollback SQL path:

```text
sql/N4_projection_matcher_rollback.sql
```

Rollback scope is the N4 execute run only. It deletes N4 outbox, trigger match/state/quality, N4 inbox rows, N4 checkpoints, and the execute run row by `execute_run_id`. It must not delete N3 facts or the original N3 outbox rows.
